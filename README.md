📋 Internship Tasks

According to the CodeAlpha task instructions, interns are required to complete any 2 or 3 tasks from the following four Python tasks.

✅ Task 1: Hangman Game

A simple text-based Hangman game where the player guesses a word one letter at a time.

Features:

- Uses a list of 5 predefined words
- Allows a maximum of 6 incorrect guesses
- Console-based input and output
- No graphics or audio

Concepts Used:

- "random"
- Lists
- Strings
- "while" loop
- "if-else"

---

✅ Task 2: Stock Portfolio Tracker

A simple program that calculates the total investment value based on stock names, quantities, and predefined stock prices.

Features:

- User enters stock names
- User enters the quantity of each stock
- Stock prices are stored in a dictionary
- Calculates total investment value
- Results can optionally be saved to a ".txt" or ".csv" file

Example:

stock_prices = {
    "AAPL": 180,
    "TSLA": 250
}

Concepts Used:

- Dictionaries
- Input/Output
- Basic arithmetic
- File handling

---

✅ Task 3: Task Automation with Python Scripts

This task involves automating a small repetitive real-life task using Python.

Possible Projects:

1. Move all ".jpg" files from one folder to another.
2. Extract email addresses from a ".txt" file and save them to another file.
3. Scrape the title of a fixed webpage and save it.

Concepts/Libraries Used:

- "os"
- "shutil"
- "re"
- "requests"
- File handling

---

✅ Task 4: Basic Chatbot

A simple rule-based chatbot that responds to predefined user messages.

Example Inputs:

hello
how are you
bye

Example Responses:

Hi!
I'm fine, thanks!
Goodbye!

Concepts Used:

- "if-elif"
- Functions
- Loops
- Input/Output
